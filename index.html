사진의 고정수당을 초기값으로 넣었습니다. 시간외수당 659,630원과 일시 지급 61,290원은 제외하고, 시간외 시간·단가를 직접 입력하도록 했습니다. 승진·보직 변경 시 금액을 바꿔주세요.

명세서 밖 수령·복지포인트

출장비·당직비는 월급명세서 세전급여와 공제 계산에서 분리한 뒤 통장 수령 합계에 더합니다. 복지포인트는 현금이 아니므로 따로 표시하며, 지정월의 연간 사용가능액을 기간 합계에 한 번 반영합니다. 실제 과세 처리나 지급 시점이 다르면 값을 조정하세요.

세금·보험·연금

소득세는 연환산 간이 추정치입니다. 실제 원천징수세액, 건강보험 정산액, 연금 기준소득월액은 명세서와 차이 날 수 있습니다.

향후 연도 가정

2027년 이후 봉급·세율·수당은 확정표 자동 갱신이 아닙니다. 입력한 연금·건보 기준액은 시작 연도 기준으로 두고, 이후 연도에는 가정한 봉급 인상률만큼 조정합니다. 실제 재산정액을 알면 다시 입력하세요.

기준과 계산 범위

2026년 소방공무원 봉급표, 정액급식비 16만 원, 계급별 직급보조비, 정근수당·가산금, 명절휴가비 60%를 반영했습니다. 건강보험은 입력한 보수월액의 총 보험료율 절반, 장기요양은 건강보험료의 비율, 공무원연금 기여금은 기준소득월액의 기여율로 예상합니다. 성과상여금은 2026년 계급별 지급기준액과 S·A·B 표준 지급률을 쓰며, 기관별 지급계획과 다르면 기준액·지급률을 직접 조정하세요. 출장비·당직비는 명세서 공제 계산 밖의 별도 수령액, 복지포인트는 비현금 항목으로 계산합니다. 세금은 공식 간이세액표를 그대로 조회하는 방식이 아닌 연환산 근사치이며 연말정산을 포함하지 않습니다.
